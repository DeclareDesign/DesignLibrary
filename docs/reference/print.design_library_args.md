# Print the parameter table from get_args()

The `default` column holds the values themselves, and a function or a
list has no one-line form, so the printed table shows `value_str` in its
place.

## Usage

``` r
# S3 method for class 'design_library_args'
print(x, ...)
```

## Arguments

- x:

  A `design_library_args` table.

- ...:

  Unused.

## Value

`x`, invisibly.
