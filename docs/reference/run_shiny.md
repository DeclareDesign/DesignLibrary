# Launch the DesignLibrary Shiny browser

Launch the DesignLibrary Shiny browser

## Usage

``` r
run_shiny(...)
```

## Arguments

- ...:

  Passed to
  [`shiny::runApp()`](https://rdrr.io/pkg/shiny/man/runApp.html).

## Value

The value of
[`shiny::runApp()`](https://rdrr.io/pkg/shiny/man/runApp.html) (called
for side effects).
